# aerobeat-web-renderer

AeroBeat-owned PlayCanvas renderer for canonical GLB gameplay visuals, bounded world feedback, and normalized landmark overlays.

## Responsibility

This package owns one PlayCanvas `Application` and graphics device per attached gameplay canvas, exact container/DPR sizing, deterministic world-scene projection, pinned canonical GLB loading and instancing, renderer-local bounded feedback glyphs and guidance bands, retained compatibility-only branding atlas upload, context recovery, visual-only debug camera controls, bounded resource pooling, capability truth, and deterministic teardown.

It does not own media, CV, the calibrated athlete grid, gameplay input, score or judgement decisions, content loading, song time, transport, DOM presenters, or assembly policy. Every frame is derived from caller-owned absolute `nowMs` and resolved target records. Continuous walls consume the shared mode-neutral `aerobeat_top_left_grid` gameplay geometry (positive height downward) in Flow and Boxing Grid. Boxing Lanes and Collider use the same canonical wall and exact interval: each weave is one two-column-wide, full-three-row wall centered on its authored side, and each squat is one full-four-column wall extending from three rows above the grid through half the second row (4.5 rows total); configurable center separation is applied consistently to legacy timing tiles (when settings are absent), targets, and walls, and walls cast native directional shadows without fake floor geometry. Obstacle targets without normalized continuous geometry fail rather than falling back to the generic circle, and assembly does not layer static per-cell obstacle duplicates over these walls.

Legacy normalized `x/y`, direction, Euler, and scalar-rotation aliases reject. Each role owns one root carrying the projected wrist position, positive uniform scale, and final quaternion; shipped saber `-Z`, native-Y fallback cylinders/glow, glove offsets, and right-hand mirroring are child-local corrections only.

## World and timing contract

The authoritative body grid is row-major from top-left and uses one equal world unit per canonical cell. A strict private `showGameplayGrid` frame boolean defaults hidden and only exact `true` enables the twelve neutral Flow/Boxing Grid faces; safe/blocked overlays, track, targets, walls, feedback, and separately staged markers remain; timing tiles remain only for settings-absent legacy frames, while Boxing Lanes never creates the floor. Grid coordinates use one equal world unit per canonical cell: four columns map to X `[-1.5, -0.5, 0.5, 1.5]`, and three rows map to Y `[2, 1, 0]`. Visible neutral/safe/blocked cell faces use equal X/Y insets inside that pitch, and normalized calibrated cursors use the same `4 × 3` outer bounds. Time maps only to world Z with `z = -(timestampMs - nowMs) * worldUnitsPerMs`: future events are farther toward world `-Z` and approach zero. The fixed athlete camera sits on world `+Z`, looks along camera-local/world `-Z`, and therefore projects world `+X` screen-right. Source scoring cells, timestamps, judgements, variants, and conversion records are never rewritten by the renderer.

One canonical `aerobeat/gameplay_camera_pose` v1 record owns fixed play, debug initialization, Reset, and projection. Its conventions are `playcanvas_world`, `right_handed`, world up `+Y`, camera forward `local_-Z`, and timeline future `world_-Z`; roll is exactly zero. Authoring bounds are position X `[-40,40]`, Y `[-8,32]`, Z `[-72,32]`; pitch `[-77.349303,77.349303]` degrees; finite yaw input `[-360000,360000]` normalized to `[-180,180)`; vertical FOV `[1,179]`; near clip `[0.001,10]`; far clip `[1,10000]`; and near must remain below far. Derrick's reviewed canonical artifact replaces the migrated default with position `(0.05,1,5)`, Euler `(0,0,0)`, and projection `(48,0.1,80)`; later loaded poses remain live Visual Test state unless a separately reviewed source change explicitly replaces this default.

The model derives green/yellow/red timing-window bounds from caller timing data. Flow always uses unit front/back *note-time* depth regardless of rotating saber forward/rear reach (including rear `0`); Boxing alone applies configured front/back depth to timing bounds. Only settings-absent legacy frames tile those bounds across canonical presentation lanes, with clipped boundary tiles and no invented cues; configured collider frames emit no timing tiles, even when collider visibility is off. The legacy 7.3-wide timing slabs and timing rings/circles do not exist. Opaque canonical targets and marker spheres use normal depth testing/writes. Renderer-owned Grid, Guidance Bands, then semantic Targets layers sit after the Skybox and before World transparency, without a depth clear: calibrated grid/cell faces cannot color-wash approaching targets, prior opaque World depth and target-target depth remain physical, and only note/guard/bomb assets receive this deliberate readability exception. Glass track and wall bodies retain authored transparency, later World ordering, depth testing, and disabled body depth writes; feedback and markers retain their prior World behavior.

Flow Grid and Flow Colliders both select the exact renderer presentation identity `flow`; this package owns no ruleset or scoring branch. The Flow Show capsule's fill and wire use a post-World transparent layer. Boxer Show uses a translucent flat-ended cylinder fill and retained charcoal polygon rims/longitudes at the cylinder surface in the original pre-World collider layer. Its local +Z axis follows each resolved glove pose final quaternion; at Scale 1 / Depth +1 / −0, the back/front are glove local −.29/+ .39 WU and the radius is .34 WU. ## Hit aftermath fade (private frame seam)

`frame.aftermathFadeByMode` is optional; when absent, corpses retain the original offscreen/eviction fade. When present it must contain exact plain `flow` and `boxing` records, each `{enabled:boolean,delayMs:number,durationMs:number}` with finite nonnegative floats and no arbitrary maximum. Flow aftermath uses `flow`; punch, guard, obstacle, bomb and safe use `boxing`. Disabled timers preserve the original fade. Enabled timers keep full opacity through the delay measured from `hitCommitMs`, fade linearly over the duration, and disappear at its end; zero duration hides at the delay boundary. Offscreen crossing no longer shortens an enabled timer, while caller-owned bounded FIFO eviction and cleanup remain unchanged. Alpha uses the existing native GLB transparency/depth path, not a shader or dither. Malformed present settings reject before scene objects are staged. This renderer does not own the public Game Setup controls or persistence.

## Manual PlayCanvas lifecycle

Assembly owns the display cadence. The facade never starts an engine RAF and never advances gameplay time. PlayCanvas 2.x still requires its per-application activation/update path, so each facade disables `Application.requestAnimationFrame` and invokes bounded manual ticks only from caller render requests. The production assembly stages gameplay and current/empty cursors through `renderGameplayFrameWithCursors`, producing exactly one manual tick per display opportunity instead of separately rendering the same scene twice. Initial framegraph/application activation is bootstrapped synchronously. Entities are constructed with their explicit owning application so multiple `<aero-game>` instances remain isolated.

Context loss removes the private atlas texture, pinned gameplay containers, and optional assembly-described photosphere resources. Context restoration starts fresh gameplay and environment generations, reapplies the latest retained transform, and rejects stale fetch/decode completion. Descriptor replacement first validates without mutation, then synchronously aborts and disposes the prior generation before loading; at most one environment texture/root is resident. Replacement failure shows the existing gradient rather than the previous or wrong asset. The environment is one radius-30 outward-wound procedural sphere (16×32 bands, 1,024 triangles) in PlayCanvas's built-in Skybox layer. Its renderer-owned unlit/emissive JPEG texture uses opaque blending, front-face culling, disabled frustum culling, and disabled depth test/write, so it stays behind all gameplay including the track through world `z=−72`. UV geometry directly preserves source `−Z` center, `+Y` up, and left/right orientation without mirroring. Its root follows camera translation plus configured position, never inherits camera rotation, applies pitch/X, yaw/Y, roll/Z, and reports truthful uniform root scale; centered scale changes sphere radius but not angular zoom. The next caller-owned render recreates the atlas, avoiding stale extension state and autonomous recovery timers. `detach()` and synchronous idempotent `destroy()` abort pending fetch/decode work and release decoded image, sphere mesh, material, texture, listeners, entities, gameplay container assets, the application, and pointer lock. No engine RAF or non-package asset request is introduced.

## First Flow cut

When the pinned arrow and Any-orb GLBs become ready, the renderer builds two arrow halves and four Any-orb halves (enough for the scored two-Any burst) and draws their real clipped meshes into a private target on the same PlayCanvas device. This links both signed shaders before a scored Flow frame without painting the canvas, advancing gameplay, or adding a RAF.
