Production asset pins, signed service, scene-model knee kind, gameplay, tracking and scoring are untouched. Existing 44 original back-facing and 44 corrected front-facing PNGs remain in their separate sibling review folders; do not overwrite them with this mode.

The phone renderer's existing DPR cap is 2, so the WebGL framebuffer is 780×1688 and saved PNG is CSS 390×844. The comparison punch arrow, paired guard shields, canonical four-column track and camera come from the existing native renderer/scene model. Target X/Y comes from its grid, Z/scale from the real punch at the same timestamp; the new candidate is visually staged, **not** an authored or scored knee beat. Per its source manifest, this hover shell's intended camera view is world +Z at identity rotation; unlike the earlier strapped targets, it is not yawed 180°. The model retains its authored fixed white/lime/cyan colors; it has no runtime target tint. `bounds.json` records projected GLB corner bounds and native material state: cyan rim opacity ≈0.82, blendType 2, depth test on, depth write off. This verifies a translucent native GLB material and visible pixels; the image alone does **not** prove detailed alpha sorting against all backgrounds or isolate front/back rim pixels.

The eight pad PNGs cover paired lowered/raised positions on plain **representative neutral cylinder legs** in cyan/magenta and yellow/royal-blue tint pairs, landscape/phone.
