# Front-facing provisional knee art — native PlayCanvas review

Run `node scripts/review-knee-art-browser.js --face-player` from the renderer root. This test-only mode stages provisional target GLBs at exactly the same four-column Boxing Grid X/Y and timestamp-based Z as the original review, but turns each candidate **180° around world Y** before rendering. That maps its authored local −Z outer front toward the canonical camera at world +Z. The pad instances receive the same 180° base yaw plus the existing illustrative left/right lowered/raised leg-pose rotations. There is **no product runtime transform or knee gameplay implementation** in this mode.

The 44 new PNGs cover three target variants × left/right × FAR (1400 ms)/NEAR (420 ms)/HIT distance (0 ms) × landscape 844×390 and phone CSS 390×844, plus eight pad lowered/raised × two contrasting color pairs × both viewports. Original 44 back-facing images remain in the sibling `knee-art-2026-10-20/` folder, untouched. `bounds.json` records world-transformed candidate-corner projected boxes, actual native camera pose/FOV, GLB hashes, the authored-front world direction, real canonical track/punch/paired-guard IDs, and framebuffer pixel checks. A candidate must be nonblank and its authored front must point toward +Z. The native PlayCanvas framebuffer is 844×390 at DPR1 landscape, 780×1688 at browser DPR3 phone because the **existing renderer DPR cap is 2**; saved PNGs are CSS-scale 390×844 on phone.

Visual inspection alongside Blender candidate `views/front.png` shows the front shell/rim-and-strap treatment rather than the prior rear: compare `turtle-shell-strap-v1-left-hit-phone.png` with its original counterpart and the candidate front source render. The pad shell reads as the authored broad dome in the front-facing raised-pose capture. This is a qualitative, source-image comparison, **not** a pixel-parity claim: lighting, color overrides, leg pose, perspective and track differ. FAR landscape candidates remain ~15–21 CSS pixels wide, and some touch the glass-track edge. Illustrative cylinder legs are not measured anatomy or MediaPipe tracking. No images claim scored hits, physical fit, canonical release or any human approval. Pad `.9` and target `.10` remain separate OPEN decisions; Derrick must judge both, including orientation and small-size readability.
